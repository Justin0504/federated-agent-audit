# Social audit concept demo

Open `index.html` in a browser. It is a self-contained, offline storyboard with four auditor views and an auxiliary-graph clue toggle. Messages, names and graphs are invented. It makes no model/API calls, sends no data, and does not run the FAA detector. Clicking controls changes a scripted view, not an experimental result. External reference links are followed only if clicked.

The recipient sees both message fragments in every mode. Only the auditor graph view changes. This separation matters: pseudonymizing an audit report cannot retract information already delivered to a recipient. Window mode suppresses selected edges by construction; no guarantee of anonymity or retained audit recall is implied.

The paper's prospective protocol proposes 120 workflow clusters × 3 membership conditions × 4 reporting views = 1,440 episodes per model/seed. These are planned, not run. WhatsApp and Instagram are application motivations; there is no connector, real user data, platform endorsement or claim about available group APIs.

The denser storyboard adds WhatsApp-like group and Instagram-like Story/DM visual cues, three agent roles and a three-step recipient narrative. These are original conceptual UI shapes, not official logos or platform screenshots. Completed paper evidence is displayed separately from the unexecuted study design. Four auditor views and the auxiliary-graph clue remain scripted.
